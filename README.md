# しきつめパズル

正方形のわくに、ピース(ポリオミノ)をすき間なく敷き詰めるパズルです。
ブラウザだけで動き、スマホにはアプリとしてインストールできます(PWA)。

![board](https://img.shields.io/badge/board-4%C3%974%20%E3%80%9C%2010%C3%9710-blue)

## とくちょう

- **問題は毎回その場で自動生成**。正方形をランダムに分割して作るので、**かならず解けます**。
- **むずかしさは 5 段階**

  | むずかしさ | 盤面 | ピース | 個数 |
  | --- | --- | --- | --- |
  | れんしゅう | 4×4 | 4 マス | 4 |
  | やさしい | 5×5 | 5 マス | 5 |
  | ふつう | 6×6 | 4 マス | 9 |
  | むずかしい | 8×8 | 4 マス | 16 |
  | おに | 10×10 | 5 マス | 20 |

- ドラッグで配置、タップで回転、ボタンで反転。**マウスでも指でも**遊べます。
- 選んでいるピースはわくが光り、回転・反転はアニメーションで向きの変化が分かります。
- タイム計測・自己ベスト記録・戻す・ヒント・やり直し。
- 途中でやめても**続きから**再開できます(リロードしても消えません)。
- オフライン対応。ライト/ダークテーマ自動切り替え。

## あそびかた

1. 下のピースをドラッグして、正方形のわくに置く。
2. ピースをタップすると選ばれて**わくが光ります**。もう一度タップで **回転**。反転は「反転」ボタン。
   まわしてもトレイの並びは動かないので、続けてたたけます。
3. 置いたピースはタップで手もとに戻る。ドラッグで置き直しもできる。
4. わくをすき間なく埋めたらクリア。

キーボード: `R` 回転 / `F` 反転 / `U` 戻す / `H` ヒント / `N` 新しい問題 / `Esc` 選択解除

## 動かす

ビルドは不要です。

```bash
npm start          # http://localhost:8080/ で開く
```

`index.html` をブラウザで直接開いても遊べますが、
`file://` ではオフライン機能(Service Worker)は無効になります。

### スマホにインストールする

HTTPS で公開したページを開き、ブラウザのメニューから
「ホーム画面に追加」/「アプリをインストール」を選ぶと、
アプリとして単独のウィンドウで起動します。

### GitHub Pages で公開する

**Settings → Pages → Source** を **Deploy from a branch** にして、
公開したいブランチと `/ (root)` を選ぶだけです。ビルドが要らないので、
push するたびに GitHub がそのまま配信してくれます。

## テスト

```bash
npm test           # 問題生成のテスト (node:test)
```

盤面を過不足なく覆うか、ピースが連結しているか、同じ seed で同じ問題になるかを、
全むずかしさ × 20 問ぶん検証します。

## 仕組み

`src/puzzle.js` が問題を作ります。

1. 空きマスのうち左上のものを起点に、そこを含む **k マスの連結形をすべて列挙**する。
2. ランダムな順に試し、置くたびに **残りの空き領域のマス数が k の倍数か**を確認する
   (倍数でなければその先で必ず詰むので、その時点で枝刈りする)。
3. 埋まるまで再帰。行き詰まったら戻ってやり直す。

分割そのものが解答なので、ヒントは常に正解を出せます。
プレイヤーには各ピースをランダムな向きにして渡すので、見た目からは解答が分かりません。

同じ seed からは必ず同じ問題ができます(`Puzzle.mulberry32`)。
これを使って、途中経過は「seed + 各ピースの向きと位置」だけで保存しています。

## ファイル

```
src/puzzle.js           問題生成・ポリオミノの回転/反転(ブラウザと Node の両方で動く)
src/game.js             操作・描画・保存
test/puzzle.test.js     問題生成のテスト
scripts/serve.js        開発用の静的サーバー
sw.js, manifest.webmanifest, icon*.svg   PWA まわり
```
