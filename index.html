あそびかた

  1. 下のピースをドラッグして、正方形のわくに置きます。
  2. ピースをタップ(クリック)すると選択、もう一度タップで回転します。
  3. 選択中のピースは 回転 / 反転 ボタンでも向きを変えられます。
  4. 置いたピースはタップで手もとに戻せます。ドラッグで置き直しもできます。
  5. わくをすき間なく埋めたらクリアです。

問題は毎回その場で作られ、かならず解けるようになっています。

キーボード: R 回転 / F 反転 / U 戻す / H ヒント / N 新しい問題
